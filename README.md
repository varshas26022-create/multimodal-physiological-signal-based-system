
# Multimodal Physiological Signal-Based System for Real-Time Neuromuscular Cramp Risk Prediction

A hybrid wearable healthcare system developed for real-time neuromuscular cramp risk prediction using multimodal physiological signal acquisition.

---

## 📌 Overview

This project integrates multiple physiological sensors to continuously monitor muscle activity and predict possible cramp occurrences before onset.

The system combines:

- EMG Sensor
- GSR Sensor
- Flex Sensor

with Arduino-based acquisition for real-time monitoring and analysis.

---

## 🚀 Key Features

- Multimodal physiological signal acquisition
- Real-time neuromuscular monitoring
- Hybrid sensor integration
- Arduino-based wearable architecture
- AI-assisted cramp risk prediction
- Preventive healthcare application

---

## 🛠️ Technologies Used

- Python
- Arduino
- EMG Sensor
- GSR Sensor
- Flex Sensor
- Machine Learning
- Biomedical Signal Processing

---

## 🎯 Objective

To develop a smart wearable healthcare system capable of identifying neuromuscular cramp risk using hybrid physiological signal analysis for athlete safety and preventive healthcare monitoring.
